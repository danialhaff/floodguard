1. PENGENALAN & LATAR BELAKANG PROJEK

Taman Sri Muda, Shah Alam merupakan salah satu penempatan kediaman berkepadatan tinggi yang paling terdedah kepada bencana banjir kilat dan banjir monsun di Malaysia. Peristiwa banjir besar pada 17 hingga 18 Disember 2021 telah menenggelamkan ribuan kediaman, meragut nyawa, serta melumpuhkan akses komunikasi dan operasi menyelamat. Keadaan ini berpunca daripada gabungan hujan luar biasa, ketinggian topografi tanah yang amat rendah berbanding paras Sungai Klang, dan kelemahan dalam sistem penyelarasan evakuasi penduduk ke Pusat Pemindahan Sementara (PPS).

FloodGuard dibangunkan sebagai penyelesaian kejuruteraan perisian berteraskan sistem maklumat geografi (GIS) dan model elevasi digital (DEM) untuk menyediakan amaran awal pintar, visualisasi simulasi banjir dinamik, panduan laluan keluar selamat bagi penduduk, serta papan pemuka arahan operasi menyelamat bersepadu untuk agensi responder seperti Jabatan Bomba dan Penyelamat Malaysia (JBPM) dan NADMA.

2. SENIBINA TEKNOLOGI & ALAT (TECH STACK)

Sistem FloodGuard dibina dengan integrasi teknologi moden merangkumi bahagian hadapan (Frontend), bahagian belakang (Backend), pemprosesan spatial satelit, dan pangkalan data berprestasi tinggi:

Lapisan (Layer) Teknologi / Pustaka Peranan & Fungsi Utama
Frontend UI/UX HTML5, CSS3 (Glassmorphism), Vanilla JavaScript (ES6+) Antara muka moden responsif bertema gelap (Dark Mode), komponen interaktif, panel kawalan simulasi, modal SOS kecemasan.
Web GIS & Peta Leaflet.js (v1.9.4) & CARTO Basemaps Enjin peta interaktif, pemaparan tile layer berkualiti tinggi, penanda PPS, garisan poligon sempadan, dan laluan navigasi kecemasan.
Backend API Python 3, FastAPI, Uvicorn RESTful API berprestasi tinggi (asynchronous), pengurusan simulasi paras air, routing titik PPS, pemprosesan panggilan SOS, dan autentikasi RBAC.
Spatial Database PostgreSQL + PostGIS (via Supabase Cloud) Pangkalan data spatial menyimpan geometri koordinat (SRID 4326/WGS84) bagi zon banjir, PPS, rekod sejarah hujan, dan kedudukan mangsa SOS.
Pemprosesan DEM/GIS Python Rasterio & NumPy Skrip pemprosesan raster satelit untuk membaca fail altitud Malaysia (MYS_alt.vrt) dan mengekstrak ketinggian tanah tepat di zon TSM.
Cuaca Masa-Nyata OpenWeatherMap API Mengambil data taburan hujan sejam (1-hour rainfall mm), suhu, dan keadaan cuaca live bagi stesen cuaca Shah Alam.
Kontena & Deployment Docker, Docker Compose, GitHub Pages Pakej kontena perkhidmatan frontend dan backend serta hos statik bagi portal web awam.

3. KETULENAN DATA GEOGRAFI & KETINGGIAN TANAH

Salah satu kekuatan utama projek FloodGuard adalah kebergantungan kepada data spatial sebenar (Real Scientific Data) dan bukan data rekaan:

Pengesahan Ketulenan Data: Data ketinggian tanah dalam projek ini adalah 100% DATA SEBENAR yang diperoleh daripada satelit NASA SRTM (Shuttle Radar Topography Mission) melalui dataset DIVA-GIS (MYS_alt).

A. Analisis Topografi Sebenar Taman Sri Muda

Melalui fail pemprosesan extract_elevation.py, ketinggian tanah diekstrak secara terus mengikut koordinat centroid setiap zon:

  • Central Zone (Tengah TSM): Paras ketinggian tanah hanya 8.7 meter dari aras laut. Ini mengesahkan hakikat geografi bahawa kawasan tengah adalah 'basin' (mangkuk tadahan) yang paling cepat ditenggelami air.
  • South Zone (Selatan TSM): Paras ketinggian sekitar 9.1 meter.
  • East Zone (Timur TSM): Paras ketinggian sekitar 10.2 meter (berdekatan laluan sungai).
  • North Zone & West Zone: Paras tanah lebih tinggi iaitu antara 11.3 meter hingga 12.5 meter.

B. Sempadan Kejiranan & Lokasi Pusat Pemindahan (PPS)

  • Sempadan Poligon Rasmi: Menggunakan 59 titik koordinat geografi sempadan rasmi Taman Sri Muda yang diekstrak daripada pangkalan data OpenStreetMap (OSM Nominatim).
  • Lokasi PPS Sebenar: Empat pusat pemindahan yang digunakan merupakan fasiliti komuniti sebenar di Shah Alam:
    1. Dewan Azalea Seksyen 25 (Kapasiti: 500 orang)
    2. SK Taman Sri Muda (Kapasiti: 800 orang)
    3. Dewan Kenangan MBSA Seksyen 28 (Kapasiti: 1,200 orang)
    4. SK Seksyen 16 Shah Alam (Kapasiti: 1,000 orang)

C. Adakah Perlu Mendapatkan Kebenaran Agensi Kerajaan?

  • Untuk Tahap Prototaip / Projek Tahun Akhir (FYP) / Penyelidikan: TIDAK PERLU. Sumber data terbuka antarabangsa (NASA SRTM, OpenStreetMap, OpenWeather) adalah sah di sisi undang-undang, diiktiraf di peringkat global, dan mematuhi standard akademik.
  • Cadangan Naik Taraf Untuk Kegunaan Kerajaan Sebenar (Production):
    • JUPEM (Jabatan Ukur dan Pemetaan Malaysia): Boleh memohon dataset LiDAR resolusi tinggi (ketepatan grid sehingga 0.5m – 1m berbanding radar satelit 30m – 90m).
    • JPS (Jabatan Pengairan dan Saliran): Boleh mengintegrasikan API sensor telemetri aras air sungai masa-nyata dari stesen Sungai Klang (portal Public InfoBanjir / PRABN).
    • JKM / NADMA: Integrasi API Info Bencana JKM untuk data pendaftaran mangsa PPS secara automatik.

4. MODUL SISTEM & KAWALAN AKSES PENGGUNA (RBAC)

Sistem FloodGuard membahagikan fungsinya kepada tiga antara muka berasingan untuk memastikan aliran kerja teratur:

A. Portal Awam (Public Portal - index.html)

  • Simulasi Gelangsar Hujan (0 – 200 mm/jam): Penduduk boleh melaras kadar hujan untuk melihat visualisasi kawasan mana yang akan dinaiki air terlebih dahulu.
  • Algoritma Simulasi Air Organik: Menggunakan gabungan Fractal Brownian Motion (FBM) noise dan Radial Distance Influence ke tebing Sungai Klang bagi menghasilkan visual banjir yang realistik dan merebak mengikut graviti tanah rendah.
  • Mod Cuaca Live: Mengambil bacaan hujan semasa secara automatik dari OpenWeatherMap.
  • Laluan Evakuasi (Evacuation Routes): Paparan laluan jalan raya keluar selamat dari zon kediaman menuju ke PPS yang sesuai.
  • Borang SOS Pantas: Pengguna hanya perlu menekan satu butang untuk menyertakan nama, nombor telefon Malaysia (disahkan dengan regex), dan lokasi koordinat GPS telefon mereka terus ke pangkalan data penyelamat.
  • Action Checklist: Senarai semak tindakan keselamatan mengikut paras risiko banjir (Safe, Low, Moderate, High, Danger).

B. Pusat Kawalan Responder / Bomba (responder.html)

  • Akses Khas: Log masuk agensi responder (ID: bomba / Katalaluan: bomba123).
  • Peta Misi Menyelamat Live: Memaparkan kedudukan pin merah mangsa banjir yang telah menekan SOS berserta nama, nombor telefon, dan koordinat tepat.
  • Operasi Dispatch: Pegawai penyelamat boleh menekan butang Dispatch Team untuk menggerakkan bot dan mengemaskini status mangsa kepada Rescued sebaik sahaja diselamatkan.
  • Pemantauan Kapasiti PPS Semasa: Memantau jumlah mangsa semasa di setiap dewan agar pasukan penyelamat tidak menghantar mangsa ke pusat pemindahan yang sudah penuh.

C. Portal Pentadbir (Admin Center - admin.html)

  • Akses Pentadbir: Log masuk pentadbir sistem (ID: admin / Katalaluan: admin123).
  • Papan Pemuka Statistik: Ringkasan bilangan zon pemantauan, jumlah kapasiti PPS, rekod panggilan SOS, dan status sistem.
  • Pengurusan Pangkalan Data (CRUD): Menambah lokasi PPS baharu, mengemas kini bilangan mangsa (occupancy), menyelaraskan nilai ketinggian zon tanah, serta mencatat log sejarah hujan banjir.

6. KESIMPULAN

Projek FloodGuard berjaya menggabungkan prinsip Kejuruteraan Perisian, Sains Data Geospatial (GIS), dan Pengurusan Bencana Alam ke dalam satu platform bersepadu. Dengan memanfaatkan data topografi saintifik sebenar (NASA SRTM DEM) serta teknologi pangkalan data spatial termaju (PostGIS), sistem ini membuktikan keupayaannya untuk meningkatkan kesiapsiagaan komuniti setempat dan mengoptimumkan operasi menyelamat pihak berkuasa semasa musim tengkujuh di Taman Sri Muda.
